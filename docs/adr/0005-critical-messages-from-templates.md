# Critical messages come from code templates

Anything the declarant could act on or rely on is written by code, never by the LLM: the read-back of the claim, the reference, coverage decisions, closings and the advice to call 112. When a turn changes the claim in a way only a template may announce (complete, confirmed, closed), the engine stops the LLM loop and speaks the template; text the LLM produced alongside tool calls is dropped. We rejected letting the LLM phrase these messages and checking them afterwards, because a hallucinated reference or "your claim is covered" is worse than a less natural sentence. LLM replies are still checked with regexes for things only code may say, but those checks only record a score and a warning, because blocking a reply on a regex would make the conversation brittle.
